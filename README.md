# MU Chat Translator (portable Chrome extension)

## Install (once)
1. Open `chrome://extensions`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked** and pick this folder (`mu-traductor`)
4. Reload the game tab

## Use
- Incoming chat: each line from another player gets its Spanish translation below it (yellow).
- Outgoing, option A: type Spanish in the game chat box, press **Ctrl+Enter** to turn it into Portuguese, then **Enter** to send.
- Outgoing, option B: **Alt+T** opens a small box, write Spanish, press Enter. The Portuguese text is put in the game chat box and copied to the clipboard.

To move it to another PC, copy the folder and repeat the install steps.
